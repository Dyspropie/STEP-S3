# STEP SEM-3 Java Assignments

This repository contains complete Java solutions for the **STEP SEM-3** curriculum across Weeks 1 to 5.

## Repository Structure

The project is structured with dedicated folders for each week:
- week1/: Arrays, Nested Loops, Character Manipulation, and Conditionals
- week2/: Strings, StringBuilder, Delimiters, Normalization, and Word Frequency
- week3/: Object-Oriented Programming (OOP), Constructors, Inheritance, Static vs. Instance, and Object Composition
- week4/: Constructor Chaining (	his(...)), Boundary Invariants, Manual Sorting, and Tiered Rate Calculations
- week5/: Access Modifiers, Package Visibility Rules, JavaBean Standards, Immutability, and Defensive Copying

## Git Branching Model

Following the assignment specification:
- **main Branch**: Contains the **first question** of each week (Problem 1), representing the primary baseline.
- **Feature Branches**: The remaining questions (Problem 2 through Problem 5) for each week are developed on dedicated feature branches branching from main.

## How to Compile & Run

To compile and run any problem:
`ash
# Compile a specific week
javac week1/*.java

# Run a specific problem (or run directly with Java single-file runner)
java week1/Problem1_ExamHallSeatDuplicationChecker.java
`
